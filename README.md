# 🌿 ESPHome: компонент для датчика CO2 HC8

Кастомный внешний компонент для **ESPHome**, добавляющий поддержку датчика **HC8** (CO2).

В стандартном ESPHome долгое время был компонент только для **MH-Z19**. HC8 использует похожий 
протокол (заголовок `0x42 0x4D`), но байты данных расположены иначе, поэтому стандартный 
компонент не подходит. Этот компонент исправляет ситуацию.

> **⚠️ Важно (обновление от 2025.12):**
> Начиная с ESPHome **2025.12.0** в официальном репозитории появился встроенный 
> компонент **`hc8`**. Если у вас свежая версия ESPHome — используйте его, отдельный 
> внешний компонент больше не обязателен.
>
> Этот репозиторий остаётся полезным для:
> - тех, кто использует **старые версии ESPHome** (до 2025.12);
> - тех, кому нужен **готовый пример** с описанием граблей;
> - тех, кто хочет посмотреть, **как устроен кастомный компонент** изнутри.

## ✅ Что проверено

- ✅ **CO₂ (ppm)** — работает.
- ⚠️ **VOC / температура / влажность** — в коде компонента поддерживаются, 
  но на конкретном экземпляре HC8 (куплен на Ozon) они не отдают корректных данных. 
  Возможно, у других моделей HC8 они работают. **Не гарантируется.**

## 🔌 Подключение

Датчик HC8 общается по **UART**, 9600 бод.

| HC8  | ESP32             |
|------|-------------------|
| VCC  | 5V (см. даташит)  |
| GND  | GND               |
| TX   | GPIO4 (RX ESP32)  |
| RX   | GPIO5 (TX ESP32)  |

⚠️ **TX датчика → RX платы**, **RX датчика → TX платы**. Не перепутать.

## 🚀 Установка

1. Скопировать папку `components/hc8_full` в корень ESPHome-проекта.
2. В своём `.yaml` добавить:

```yaml
external_components:
  - source:
      type: local
      path: components

uart:
  - id: uart_hc8
    tx_pin: GPIO5
    rx_pin: GPIO4
    baud_rate: 9600

sensor:
  - platform: hc8_full
    uart_id: uart_hc8
    update_interval: 60s
    co2:
      name: "CO₂"
